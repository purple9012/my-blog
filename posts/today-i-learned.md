블로그를 직접 만들면서 HTML, CSS, JavaScript가 각각 어떤 역할을 맡는지 다시 정리해봤습니다.

## HTML — 구조와 의미

HTML은 페이지에 어떤 내용이 있는지 뼈대를 잡는 역할입니다. `index.html`은 글 목록이 들어갈 자리를, `post.html`은 글 본문이 들어갈 자리를 미리 만들어두고, 실제 내용은 JavaScript가 채워 넣습니다. 즉 HTML은 "여기에 무엇이 들어간다"는 틀만 정의합니다.

## CSS — 보여지는 방식

CSS는 같은 구조를 어떻게 보여줄지 결정합니다. `style.css`에서 라이트/다크 모드 색상을 변수로 관리하고, 미디어 쿼리로 모바일과 데스크톱 레이아웃을 나눈 게 대표적인 예입니다. 구조(HTML)와 스타일(CSS)을 분리해두면 디자인만 바꾸고 싶을 때 CSS만 건드리면 됩니다.

## JavaScript — 동작과 데이터

JavaScript는 정적인 페이지를 실제로 "동작"하게 만드는 부분입니다.

- `markdown.js` — 마크다운 텍스트를 HTML로 변환
- `posts-data.js` — 글 원본 데이터를 보관
- `theme.js` — 다크모드 토글과 저장
- `main.js` / `post.js` — 데이터를 읽어 HTML 구조 안에 실제 내용을 채워 넣음

## 정리

결국 HTML은 틀, CSS는 옷, JavaScript는 움직임을 담당한다는 걸 직접 만들어보며 체감할 수 있었습니다. 세 가지 역할이 분리되어 있으니 각자 수정할 부분만 바꾸면 되어서 유지보수가 훨씬 편했습니다.
