# spec: AI를 위한 수학 학습 웹 (math-study)

## 1. 기술 스펙 요약

| 항목 | 내용 |
|---|---|
| 스택 | 순수 HTML + CSS + 바닐라 JS (ES5~ES2015 수준). 서버 코드·빌드·프레임워크 없음. GitHub Pages 정적 호스팅, `file://` 더블클릭 실행도 동작 |
| 수식 | KaTeX **0.16.9** (CSS + `katex.min.js` + `contrib/auto-render.min.js`), CDN: `https://cdn.jsdelivr.net/npm/katex@0.16.9/dist/...` (버전 고정). 오프라인 대비책: CDN 로드 실패 시 LaTeX 원문(`$...$`)이 그대로 보이도록 두고 상단에 "수식 로드 실패" 안내 한 줄 표시 (로컬 번들은 범위 제외) |
| 스타일 | 기존 `assets/css/style.css`(딥그린 다크 테마 변수) 링크 재사용 + 신규 `assets/css/math.css`에 학습 앱 전용 스타일만 추가 |
| 화면(HTML) | 3개: `math-study.html`(단원 목록) / `math-lesson.html?unit=ID`(단원 학습) / `math-quiz.html?unit=ID`(퀴즈) |
| 파일 구조 | 아래 트리 참고. 모든 경로는 상대경로, 파일명은 소문자(대소문자 일치) |
| 콘텐츠 데이터 형식 | **JS 파일** (`assets/js/math/units/unit-XX.js`가 `window.MATH_UNITS.push({...})` 실행). JSON은 `file://`에서 fetch가 막히므로 사용하지 않음. `<script src>` 태그로 로드 |
| 저장 | **없음.** `localStorage`/쿠키/서버 저장을 사용하지 않음 (진도·점수 기록 기능 제외). 퀴즈 점수는 결과 화면에서만 표시하고 저장하지 않음 |
| 보안 | 사용자 입력 없음(퀴즈 보기 선택만). 콘텐츠는 자작 데이터라 `innerHTML` 허용(수식 렌더용) |

파일 구조:

```
index.html                         (수정: 링크 1개 추가)
math-study.html                    (신규: 화면 1 단원 목록)
math-lesson.html                   (신규: 화면 2 단원 학습)
math-quiz.html                     (신규: 화면 3 퀴즈)
assets/css/math.css                (신규: 공통 전용 스타일)
assets/js/math/common.js           (신규: 공통 유틸 - 단원 조회, KaTeX 렌더)
assets/js/math/units-index.js      (신규: window.MATH_UNITS = [] 선언)
assets/js/math/units/unit-01.js ~ unit-04.js   (신규: 단원 데이터)
assets/js/math/list.js             (신규: 화면 1 로직)
assets/js/math/lesson.js           (신규: 화면 2 로직)
assets/js/math/quiz.js             (신규: 화면 3 로직)
```

스크립트 로드 순서(각 화면 공통): KaTeX js → auto-render → `units-index.js` → `units/unit-XX.js`들 → `common.js` → 화면별 js.

## 2. 개요와 범위

- 대상: 본인 개인 학습용. 주제는 "AI를 위한 수학" — 고등수학 복습에서 출발해 선형대수 → 미적분(경사하강법) → 확률·통계로 이어짐.
- 기능: 개념 정리(수식 포함), 문제 풀이/퀴즈(정답·해설).
- 위치: `index.html`의 새 메뉴 링크 "AI를 위한 수학".
- 제외: 진도 체크(완료 표시, 진도 요약), 퀴즈 점수·기록 저장, localStorage 사용 일체, 로그인/서버/계정, 다중 기기 동기화, 자유 서술형 채점, 타이머·랭킹, 검색, 다크/라이트 토글, 수식 오프라인 번들, 그래프 시각화 라이브러리(그림은 텍스트/표로 대체), 단원 4개 초과 콘텐츠.

## 3. 학습 로드맵과 초기 단원

흐름: 함수·지수·로그 → 벡터·행렬 → 미분·경사하강법 → 확률·통계.

| ID | 제목 | 다룰 개념 | AI 연결 포인트 |
|---|---|---|---|
| unit-01 | 함수와 지수·로그 (고등수학 복습) | 함수와 그래프, 일차·이차함수(꼭짓점), 지수함수 $a^x$, 로그 $\log_a x$ (역함수 관계), 시그모이드 $\sigma(x)=\frac{1}{1+e^{-x}}$ | 활성화 함수(시그모이드), 로그 손실 |
| unit-02 | 벡터와 행렬 (선형대수) | 벡터 덧셈·스칼라배, 내적 $a\cdot b=\sum a_i b_i$, 크기 $\lVert a\rVert$, 행렬×벡터 곱 | 데이터=벡터, 신경망 한 층 = $Wx+b$, 유사도(코사인) |
| unit-03 | 미분과 경사하강법 | 평균변화율→순간변화율, 도함수 $(x^n)'=nx^{n-1}$, 합성함수 미분(연쇄법칙), 경사하강법 $x\leftarrow x-\eta f'(x)$ | 손실 최소화, 역전파의 기초 |
| unit-04 | 확률과 통계 기초 | 확률 정의, 조건부확률 $P(A\mid B)$, 베이즈 정리, 기댓값·분산 | 분류 확률 출력, 베이즈 추론, 평균/분산 정규화 |

### 단원별 검증용 예제 (콘텐츠에 사용, 계산 확인 완료)

- unit-01: $f(x)=x^2-4x+3=(x-2)^2-1$ → 꼭짓점 $(2,-1)$, $f(0)=3$. $\log_2 8=3$, $\log_{10}1000=3$. $\sigma(0)=\frac12=0.5$.
- unit-02: $a=(1,2)$, $b=(3,4)$ → $a+b=(4,6)$, $a\cdot b=3+8=11$, $\lVert a\rVert=\sqrt5$. $\begin{pmatrix}1&2\\3&4\end{pmatrix}\begin{pmatrix}5\\6\end{pmatrix}=\begin{pmatrix}17\\39\end{pmatrix}$ (1·5+2·6=17, 3·5+4·6=39). $(1,0)\cdot(0,1)=0$ (직교).
- unit-03: $f(x)=x^2$ → $f'(x)=2x$, $f'(3)=6$. $(3x^2+2x)'=6x+2$. $f(x)=(2x+1)^2$ → $f'(x)=2(2x+1)\cdot2=8x+4$. 경사하강 $x_0=3,\eta=0.1$ → $x_1=3-0.1\cdot6=2.4$, $x_2=2.4-0.1\cdot4.8=1.92$.
- unit-04: 주사위 짝수 확률 $\frac12$. 공정한 주사위 기댓값 $E[X]=\frac{1+2+\cdots+6}{6}=3.5$, 분산 $E[X^2]-E[X]^2=\frac{91}{6}-\frac{49}{4}=\frac{35}{12}\approx2.92$. 베이즈: 유병률 $P(D)=0.01$, 민감도 $P(+\mid D)=0.9$, 위양성 $P(+\mid \lnot D)=0.1$ → $P(D\mid +)=\frac{0.9\cdot0.01}{0.9\cdot0.01+0.1\cdot0.99}=\frac{0.009}{0.108}=\frac{1}{12}\approx0.083$.

## 4. 화면 구성

공통: 기존 사이트 헤더(`site-header`, `site-title`) 골격 복사 + 본문 상단 이동 링크. 본문 폭 `var(--content-width)` 중앙, 모바일 우선, 버튼 터치 영역 약 40px.

**화면 1 — 단원 목록 (`math-study.html`)**: 단원 카드 나열, 각 카드에서 학습/퀴즈로 이동.

```
 my-blog
 AI를 위한 수학
 ┌────────────────────────────────────────┐
 │ 1. 함수와 지수·로그                     │
 │ 활성화 함수(시그모이드), 로그 손실       │
 │               [학습하기] [퀴즈]         │
 └────────────────────────────────────────┘
 ┌ 2. 벡터와 행렬 ... ────────────────────┐
```

**화면 2 — 단원 학습 (`math-lesson.html?unit=unit-01`)**: 섹션별 개념 정리(제목+본문+수식+예제), 맨 아래 "퀴즈 풀기" 링크, 이전/다음 단원 링크. 잘못된 `unit` 값이면 "단원을 찾을 수 없습니다" + 목록 링크.

```
 ← 단원 목록           1. 함수와 지수·로그
 ## 이차함수와 꼭짓점
 본문 ... $f(x)=(x-2)^2-1$ ...
 [예제] 문제 → [풀이 보기 ▼]
 ...
 [퀴즈 풀기 →]    [← 이전 단원] [다음 단원 →]
```

**화면 3 — 퀴즈 (`math-quiz.html?unit=unit-01`)**: 한 번에 한 문제, 객관식(4지선다) 선택 → "정답 확인" → 정답/오답 표시와 해설 → "다음". 끝나면 결과(점수, 화면 표시만·저장 안 함), "다시 풀기"/"단원 목록". 문제 순서는 데이터 순서 고정(보기 섞기 없음).

```
 ← 단원 목록     퀴즈: 1. 함수와 지수·로그   (2 / 5)
 문제: $\log_2 8$ 의 값은?
 (•) 3   ( ) 2   ( ) 4   ( ) 8
 [정답 확인]
 → 정답! 해설: $2^3=8$ 이므로 $\log_2 8=3$.   [다음 →]
```

## 5. 단원 콘텐츠 데이터 스키마와 새 단원 추가 방법

`assets/js/math/units/unit-XX.js` 한 파일 = 한 단원:

```js
window.MATH_UNITS.push({
  id: "unit-01",            // 고유, URL의 ?unit= 값. 파일명과 일치
  order: 1,                 // 목록 정렬 순서
  title: "함수와 지수·로그",
  summary: "활성화 함수(시그모이드), 로그 손실",   // AI 연결 포인트 한 줄
  sections: [
    { heading: "이차함수와 꼭짓점",
      body: "HTML 문자열. 수식은 $...$ (인라인), $$...$$ (블록)",
      example: { question: "HTML", solution: "HTML" }   // example은 선택
    }
  ],
  quiz: [
    { question: "HTML 문자열",
      choices: ["보기1", "보기2", "보기3", "보기4"],    // 4개 권장, HTML/수식 가능
      answer: 0,                                       // 정답 인덱스(0부터)
      explanation: "HTML 문자열" }
  ]
});
```

규칙: 문자열 안 백슬래시는 `\\frac`처럼 이스케이프(JS 문자열). 단원당 섹션 3~5개, 퀴즈 5문항.

새 단원 추가 방법 (코드 수정 없이 데이터만):
1. `units/unit-05.js`를 위 스키마로 작성.
2. 세 HTML 파일의 `units/unit-XX.js` `<script>` 목록에 한 줄 추가 (3개 파일 각각 1줄).
3. 끝. 목록·학습·퀴즈는 `MATH_UNITS`를 `order`로 정렬해 자동 생성.

(빌드 없는 구조의 한계로 2번이 필요함. 줄이려면 `common.js`에 단원 파일 목록을 한 곳에 두고 동적 로드하는 방안이 있으나 초기 범위에서는 제외.)

`common.js` 공통 API: `getUnits()`(order 정렬), `getUnit(id)`, `getQueryUnit()`, `renderMath(el)` (KaTeX 미로드 시 렌더 생략 + 안내 문구 표시).
