# spec: Todo 앱 (todo.html)

## 1. 개요 및 범위

`todo.html` 단일 파일(HTML+CSS+JS 인라인)로 만드는 원페이지 할 일 목록 앱. 빌드/프레임워크/외부 라이브러리 없음.

- 포함: 할 일 추가, 완료 토글, 삭제, 남은 개수 표시, localStorage 저장, `index.html` 링크
- 제외 (과도한 기능 금지): 수정(편집), 필터/정렬, 드래그 순서 변경, 마감일/우선순위, 다크/라이트 토글, 서버 연동

## 2. 기능 목록

| 기능 | 동작 | 근거 |
|---|---|---|
| 추가 | 입력창 + 추가 버튼, Enter로도 추가. 공백만 있으면 무시, 앞뒤 공백 trim | 핵심 기능 |
| 완료 토글 | 체크박스 클릭 시 완료(취소선+흐린 색)/해제 | 핵심 기능 |
| 삭제 | 항목별 삭제 버튼(x) | 잘못 넣은 항목 정리 필수 |
| 남은 개수 | "남은 할 일 N개" (완료 안 된 항목 수). 0개면 "모두 완료!" 대신 빈 목록 안내 | 진행 상황 한눈에 파악 |
| localStorage 저장 (제안: 포함) | 키 `todo-items`, JSON 배열 `{id, text, done}`. 로드 실패/파싱 오류 시 빈 목록으로 시작 | 새로고침 시 데이터가 사라지면 쓸모가 없음. 구현 비용 작음 |
| XSS 방지 | 항목 텍스트는 `textContent`로 렌더링 (innerHTML 금지) | 사용자 입력 안전 |

## 3. 화면 구성 (와이어프레임)

```
┌ site-header ───────────────────────────┐
│ my-blog                    [← 블로그로]│
│ 마크다운으로 쓰는 개발 기록            │
└────────────────────────────────────────┘
  할 일 목록                 (h1, serif)
  남은 할 일 3개             (muted, mono)

  [ 할 일을 입력하세요        ] [추가]

  ☐ 장보기                          [x]
  ☑ ~~운동하기~~                    [x]
  ☐ 블로그 글 쓰기                  [x]

  (비어 있을 때) 할 일이 없습니다. 하나 추가해 보세요.
┌ site-footer ───────────────────────────┐
```

- 항목은 추가 순서대로 아래로 쌓음(새 항목이 맨 아래).
- 모바일 우선, 본문 폭은 `var(--content-width)` 중앙 정렬. 버튼/체크박스 터치 영역 최소 약 40px.

## 4. 파일 구조

- 신규: `todo.html` 1개 (`<style>`, `<script>` 인라인). 다른 신규 파일 없음.
- 기존 `assets/css/style.css`는 **링크해서 사용**: 헤더/푸터/색상 변수(딥그린 단일 다크 테마: `--color-bg`, `--color-bg-elevated`, `--color-text`, `--color-text-muted`, `--color-border`, `--color-accent`, 폰트 변수)를 재사용해 사이트와 톤을 맞춘다. (참고: `game-2048.html`은 style.css + 전용 css를 쓰며, 이 앱은 전용 css 대신 인라인 `<style>`로 Todo 전용 스타일만 추가.)
- 헤더/푸터 마크업은 `index.html`과 동일한 골격을 복사한다.
- 인라인 JS는 `assets/js/` 스크립트에 의존하지 않는다.
- 접근성: 입력창 `<label>`(시각적 숨김 가능), 삭제 버튼 `aria-label`, 포커스 스타일 유지.

## 5. index.html 링크 변경

위치: `index.html` 14행, 헤더의 `<p class="site-header-links">` 안. 기존 2048 링크 뒤에 같은 방식으로 추가.

변경 전:
```html
<p class="site-header-links"><a href="game-2048.html">2048 게임</a></p>
```
변경 후:
```html
<p class="site-header-links"><a href="game-2048.html">2048 게임</a><a href="todo.html">할 일 목록</a></p>
```

- 링크 간 간격은 `style.css`의 `.site-header-links` 스타일을 구현 단계에서 확인하고, 붙어 보이면 공백 또는 구분자(` · `)로 처리한다. style.css 수정 여부는 구현 시 최소 변경으로 판단(필요하면 보고).
- `todo.html` 헤더에는 `index.html`로 돌아가는 로고 링크(`my-blog`)를 둔다.

## 6. 검증 체크리스트 (Review용)

- [ ] `todo.html` 단독으로 열렸을 때 오류(콘솔 에러) 없음, 외부 의존성 없음
- [ ] 추가: 버튼 클릭 / Enter 모두 동작, 입력창 비워지고 포커스 유지
- [ ] 공백만 입력 시 추가되지 않음
- [ ] 체크 시 취소선, 해제 시 복구. 남은 개수가 즉시 갱신
- [ ] 삭제 시 항목 제거, 남은 개수 갱신
- [ ] 빈 목록 안내 문구 표시/숨김
- [ ] 새로고침 후 항목·완료 상태 유지 (localStorage)
- [ ] localStorage 값이 깨져 있어도(잘못된 JSON) 페이지가 정상 로드
- [ ] `<script>`/HTML 태그를 입력해도 텍스트로 표시됨 (XSS 없음)
- [ ] 긴 텍스트가 레이아웃을 깨지 않음(줄바꿈)
- [ ] 기존 사이트 톤(딥그린 배경, accent 색)과 일치, 모바일 폭(약 375px)에서 정상
- [ ] `index.html` 헤더에 "할 일 목록" 링크가 보이고 클릭 시 `todo.html`로 이동, 기존 2048 링크 유지
- [ ] `todo.html` 헤더 로고로 `index.html` 복귀 가능
- [ ] 키보드만으로 추가/토글/삭제 가능

## 7. 열린 질문

1. localStorage 저장을 포함해도 되나요? (제안: 포함)
2. 완료 항목 일괄 삭제("완료 항목 지우기") 버튼은 제외로 두었는데, 필요하신가요?
3. 링크 문구는 "할 일 목록"으로 괜찮은가요? ("Todo" 등 대안 가능)
4. 간격 때문에 `style.css`의 `.site-header-links` 수정이 필요할 경우 허용하시나요? (기본: 가능하면 수정 없이 처리)
